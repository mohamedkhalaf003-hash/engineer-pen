# خطتي - نسخة أندرويد

Mohamed Abdelnasser / محمد عبد الناصر

## المطلوب
بناء ملف APK من المشروع ده باستخدام GitHub Actions.

## الخطوات
1. اعمل مستودع جديد على GitHub (Private أو Public) باسم khotati-android.
2. ارفع كل محتويات الفولدر ده عليه في الفرع main، ومعاه الفولدر المخفي .github.
3. أول ما يترفع، GitHub Actions هيشتغل لوحده (Build APK). استنى حوالي 5 دقايق.
4. الملف Khotati.apk هيظهر في صفحة Releases في المستودع. ابعت رابط التحميل لمحمد.

لو البناء فشل: افتح تبويب Actions، شوف رسالة الخطأ، صلّحها، وارفع التعديل.

## نص جاهز تلصقه في Claude عند صاحبك
عندي فولدر مشروع أندرويد اسمه khotati-android (مرفق مضغوط). اعمل مستودع جديد على GitHub باسم khotati-android وارفع عليه المحتوى كله في فرع main مع الفولدر .github. المشروع فيه workflow بيبني APK بـ GitHub Actions ويحطه في Releases. تابع البناء لحد ما ينجح، ولو فشل صلّح الخطأ وارفع تاني، وفي الآخر اديني رابط تحميل Khotati.apk من صفحة Releases.
